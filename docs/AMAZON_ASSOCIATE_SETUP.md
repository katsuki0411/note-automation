# Amazon アソシエイト 申請手順書

> MultiPostAI で Amazon アフィリエイト機能を運用するための、Amazon アソシエイト・プログラムへの申請ガイド。スタッフ向け。
>
> 最終更新: 2026-06-01

---

## 0. このドキュメントの目的

MultiPostAI の `amazon_affiliate` プロジェクトで自動投稿された記事に、**Amazon アソシエイトのアフィリエイトリンク**（収益化リンク）を貼れるようにする。そのために、Amazon にアソシエイトメンバーとして登録申請する。

申請 → 仮承認 → **180日以内に3件以上の販売実績** → 本承認 → PA-API（商品情報自動取得API）申請可能、という段階がある。**今回のゴールは仮承認まで**。

---

## 1. 事前に決めること（申請開始前にチェック）

申請フォームで聞かれるので、以下を**事前に決めてから**進める。

- [ ] **申請者名義**: 個人 / 法人どちらで申請するか
  - 個人 = 個人名・自宅住所
  - 法人 = 会社名・本社住所・代表者名
- [ ] **登録Gmail**: どの Google アカウントで Amazon ログインするか（例: `michisu.inc@gmail.com`）
- [ ] **報酬受取口座**: 振込先の銀行口座（5,000円以上で振込発生）
- [ ] **電話番号**: 申請時の PIN コード認証に使う
- [ ] **紹介サイト**: アフィリエイトリンクを貼る予定のサイト or SNS
  - 最低1個、できれば3個まで登録すると審査通りやすい
  - サイトはなるべく**記事が3〜5本以上公開済み**のものが望ましい
  - 例候補: 自分のブログ / Blogger / note / X / Instagram

> 💡 **重要**: 記事ゼロの空サイトで申請すると審査落ちしやすい。事前に最低3本くらい記事を公開しておくと安全。

## 2. 申請前に知っておくべきルール（必読）

### 2-1. 180日3件ルール（最大の難関）

- 仮承認後、**180日以内に3件以上の商品販売**が必要
- 達成できないと**アカウント停止**（再申請は可能だが180日待つ必要あり）
- 「クリック」ではなく「**実購入**」で3件

### 2-2. 一発アウト行為

以下は規約違反。バレると即停止 + 過去報酬没収。

- ❌ **自己購入での報酬発生**（自分のリンクから自分で買う）
- ❌ **家族・友人による購入**でも禁止（同一世帯はNG）
- ❌ **セルフバック**目的の購入
- ❌ メール本文に直接アフィリエイトリンクを貼る（メルマガNG）
- ❌ 短縮URL等でアソシエイトIDを隠す
- ❌ 商品ページと無関係なリンク誘導
- ❌ アダルト・出会い系サイトでの使用

### 2-3. 必須表記

- 自サイトに「**当サイトは Amazon アソシエイトとして、適格販売により収入を得ています**」の文言を明記する
- ステマ規制（景表法 2023/10〜）で「PR」「広告」表記も必須

## 3. 申請手順（実作業）

### Step 1: 通常 Amazon アカウントの準備

1. https://www.amazon.co.jp/ にアクセス
2. 申請に使う Gmail で Amazon アカウントを作成（既にあれば飛ばす）
3. ログイン状態にしておく

### Step 2: アソシエイト・セントラルへ移動

1. https://affiliate.amazon.co.jp/ にアクセス
2. 画面右上の **「無料アカウントを作成」** または **「サインアップ」** をクリック
3. Amazon アカウントでログイン

### Step 3: アカウント情報入力

| 項目 | 入力内容 |
|---|---|
| 氏名 | 漢字フルネーム（個人）/ 法人名（法人） |
| 住所 | 個人なら自宅、法人なら本社 |
| 電話番号 | PIN コード受取用 |
| 担当者 | 法人の場合のみ |

### Step 4: サイト/アプリ情報登録

1. **「ウェブサイトのURL」** 欄に紹介サイトURLを入力
   - 1つずつ「+ 追加」で複数登録可能（推奨: 2〜3個）
   - 例:
     ```
     https://katsugram.blogspot.com/
     https://note.com/yourname
     https://x.com/yourname
     ```
2. **アプリのURL** は該当なければ空欄でOK

### Step 5: プロフィール作成

#### ストアID（Tracking ID）

- 申請が通ると割り当てられる固有ID
- 自分で**好きな文字列**を指定可能（例: `mpai-22`）
- 末尾の `-22` は日本Amazonの自動付与
- 後で MultiPostAI に登録する時に使う

#### サイト紹介文

- ❌ 悪い例: 「いろいろな商品を紹介します」
- ✅ 良い例: 「30〜40代主婦向けに、家事・育児を楽にする時短家電やキッチン用品をブログ記事でレビュー紹介するサイト」
- **どんなジャンルの商品を、どんな読者に紹介するか**を具体的に

#### 主な集客方法

- 「SEO」「SNS」「メルマガ」等の中から該当を選択
- 月間訪問者数も入力（少なめでも正直に。0でも申請は通る）

### Step 6: 紹介する商品ジャンル選択

- 興味のある商品カテゴリを複数選択
- 後で他カテゴリの商品も紹介できるが、ここは「主に扱う予定」を選ぶ
- 例: 「ホーム&キッチン」「本」「家電」「ベビー&マタニティ」

### Step 7: 電話番号 PIN 認証

1. 「自動音声」 or 「SMS」を選択
2. 電話を受ける → 4桁の PIN が読み上げ・SMS で届く
3. 画面に PIN を入力

### Step 8: 利用規約の同意 → 申請完了

1. アソシエイト・プログラム運営規約に同意
2. 「同意する」ボタンクリック
3. **完了画面が出れば申請受理**

---

## 4. 申請直後にやること

### 4-1. 仮承認 ステータスの確認

- 申請後、Amazon から「アソシエイト登録ありがとうございます」メールが届く（即時〜1日以内）
- これは **仮承認** = リンク作成・販売開始してOK の状態
- まだ本承認ではないので、報酬は未確定

### 4-2. ストアID（Tracking ID）の控え

1. https://affiliate.amazon.co.jp/home にログイン
2. 右上のメニュー → 「アカウントの管理」 → 「トラッキング ID の管理」
3. 表示されている **`xxxxxx-22`** をメモ
4. これを MultiPostAI の設定画面に登録（後述）

### 4-3. サイトに必須表記を追加

各サイトのフッターやプロフィール欄に追加:

```
当サイトはAmazon.co.jpを宣伝しリンクすることによって
サイトが紹介料を獲得できる手段を提供することを目的に
設定されたアフィリエイトプログラムである、
Amazon.co.jpアソシエイト・プログラムの参加者です。
```

または短縮版:

```
当サイトは Amazon アソシエイト・プログラムの参加者です。
適格販売により収入を得ています。
```

## 5. 仮承認後の運用 〜 本承認まで

### 5-1. リンクの取り方（手動）

1. アソシエイト・セントラル右上の **「商品リンク」** → 「商品リンク」
2. 商品名 / ASIN / 商品ページURL いずれかで検索
3. 検索結果の右側「リンク作成」をクリック
4. 「テキストのみ」「画像のみ」「テキスト+画像」を選択
5. HTML スニペットが生成される → コピーしてブログに貼る

### 5-2. ASIN とは

- Amazon の商品識別ID（10桁の英数字）
- 商品ページURL の `/dp/XXXXXXXXXX/` 部分
- 例: `https://www.amazon.co.jp/dp/B0CD4HW6PT/` → ASIN は `B0CD4HW6PT`

### 5-3. 180日3件達成の戦略

180日 = 約6ヶ月。**早く3件売る**ほうがリスク回避になる。

| 戦略 | やり方 |
|---|---|
| **記事を3〜5本同時に出す** | 1本だけだと露出少ない。複数記事の同時稼働で確率UP |
| **検索ボリュームありの商品を選ぶ** | MultiPostAI 商品スカウト or ベストセラー機能で選定 |
| **SNS でも記事拡散** | X / Instagram でブログURLをシェア（リンク直貼りはNGだが、ブログ経由ならOK） |
| **記事公開後の追記** | 「実際に買って使ってみた」レビュー追加で滞在時間UP |
| **季節・トレンド商品狙い** | 母の日 / クリスマス / 新生活シーズン等の旬を狙う |

### 5-4. やってはいけないこと（再掲）

- ⚠️ 自分・家族の購入での実績稼ぎは **絶対にやらない**
- ⚠️ Amazon は IP / 配送先 / クレカ / アカウント情報で関連性を検出する
- ⚠️ バレると永久BAN

### 5-5. 進捗の確認

- アソシエイト・セントラル → 「レポート」で**販売実績・収益**が確認可能
- 「適格販売」欄が3件以上になったら本承認の目安

## 6. 本承認後（PA-API 申請）

180日以内に3件売れたら自動で本承認になる。**本承認後にやること**:

### 6-1. PA-API キー発行

1. https://affiliate.amazon.co.jp/assoc_credentials/home にアクセス
2. 「アクセスキーを追加」をクリック
3. **Access Key ID** と **Secret Access Key** が表示される
4. **Secret は1度しか表示されない** ので、必ずコピーして安全な場所に保管
5. 紛失したら作り直し可能（最大2個まで保有）

### 6-2. PA-API 維持条件（要注意）

- 過去30日に **3件以上の販売実績** が必要
- 達成できないと PA-API アクセスが一時剥奪される
- 売れない月が続くと無効化 → 再有効化はまた販売実績必要

### 6-3. PA-API の用途

- 商品情報（タイトル / 画像 / 価格 / レビュー数）を自動取得
- MultiPostAI 側で商品データを自動補完できるようになる
- リクエスト上限: 最低 8,640 req/日 = 1秒1回まで（売上に応じて増える）

1. MultiPostAI の `/settings` → 「Amazon アフィリエイト」タブ
2. **トラッキングID**（例: `mpai-22`）を入力 → 保存
3. 記事生成時に Amazon リンクへ自動でタグが付加される
4. 本承認後は PA-API キーも入力 → 商品情報自動取得 ON

## 8. トラブルシューティング

### Q. 申請が却下された

- 主な原因:
  - 紹介サイトの記事が少なすぎる
  - サイト紹介文が抽象的すぎる
  - サイト内容が Amazon 規約違反（アダルト等）
- 対処: サイトに記事を増やす → 紹介文を具体化 → 30日後に再申請

### Q. 180日以内に3件売れなかった

- アカウント停止メールが届く
- 過去のクリックデータ等は保持される
- 再申請は可能。**ただし販売実績ゼロのままだとまた停止**するので、サイト改善してから

### Q. PA-API キーが使えない（401 エラー）

- 過去30日の販売実績が3件未満で剥奪されている可能性
- アソシエイト・セントラルで実績確認 → 不足なら通常リンクで販売を稼ぐ

### Q. 紹介リンク経由の購入が成果に反映されない

- 24時間以内の購入なら反映される（**24時間 Cookie**）
- ユーザーがブラウザのプライベートモードや Cookie 削除を使うと反映されない
- アプリ経由の購入は反映されないケースあり
