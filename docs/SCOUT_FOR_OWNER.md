# 商品スカウト機能 — オーナー向け説明資料

> Amazon の売れ筋から「個人ブログで検索上位を取れそうなキーワード」だけを AI が見つける機能。
> 量より質。書いてもアクセスが取れないムダ記事を防ぐための事前フィルター。

---

## ① これは何のための機能か

**問題**: Amazon のベストセラー商品をそのまま記事化しても、検索結果は **Amazon / 楽天 / 大手比較サイト (mybest, kakaku.com 等)** が独占している。個人ブログが入り込む隙間がない KW で記事を書いても、アクセスは取れない。

**解決**: 「勝てそうな KW」だけに絞り込んで記事を書く。スカウト機能が事前に判定する。

```
従来:  全商品 → 全部記事化 → 多くは検索順位低くてアクセス無し
新方式: 全商品 → スカウトで絞込 → 勝てる KW だけ記事化 → アクセス効率UP
```

└────────────────────────┬────────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────────┐
│ ステップ① AI が関連キーワードを 8〜12個 発掘                │

## ③ 「勝てそうか」を判定する 2つのエンジン

それぞれ独立で評価して、UI に**並べて表示**。最終判断は人間がする。

### エンジン A 🔵 ルールベース判定

検索結果の上位 30 件を、**4種類のサイト**に分類して比率を見る。

| 上位に並ぶサイト | 個人ブログにとって |
|---|---|
| 🛒 **大手 EC** (Amazon, 楽天, Yahoo!ショッピング) | 🟢 **チャンス!** 商品ページばかりで解説記事が少ない = 個人の解説記事が入る隙間あり |
| 📰 **大手比較メディア** (mybest, kakaku.com, monomag 等) | 🔴 **厳しい** 専門ライターと SEO 投資の塊。個人ブログは勝てない |
| 📝 **個人ブログ** (はてな, livedoor, note 等) | 🔴 **飽和** 既に大量の人が記事を書いている。新規参入は不利 |
| ❓ **その他** (公式メーカー / 業界メディア等) | グレー |

#### 判定ルール

```
🛒 大手EC が多い (40%超) → ◎ 易 (隙間あり)
📰 大手メディアが多い (40%超) → ✕ 難 (専門メディア独占)
📝 個人ブログが多い (50%超) → ✕ 難 (飽和市場)
それ以外 (ミックス)        → △ 中
```

### エンジン B 🟣 AI 判断 (5つの観点)

AI に検索結果一覧を見せて、人間の専門家のように 5つの観点で評価させる。

| 観点 | 何を見ているか | 0-100 の意味 |
|---|---|---|
| **権威性** | 上位に強豪サイトがどれだけ並んでいるか | 高 = 強豪少ない = 個人有利 |
| **検索意図のズレ** | 「比較を求めて検索したのに上位が商品ページばかり」のような **ニーズと SERP の食い違い** | 高 = ニーズが満たされてない = チャンス |
| **個人ブログの余地** | 解説記事が入り込む物理的な空き枠 | 高 = 空き枠多い |
| **AI検索 引用適性** | ChatGPT, Perplexity 等 が引用元として拾いやすい KW か | 高 = 将来の AI 検索流入に強い |
| **動画/SNS の少なさ** | YouTube や Twitter が上位に多いと、文字記事は不利 | 高 = 動画少なめ = 文字記事に有利 |

#### 総合スコア (overall) の計算

5観点を**重要度で加重平均**:

| 観点 | 重み | 重みの理由 |
|---|---|---|
| 検索意図のズレ | **30%** | 一番のチャンス指標。ニーズと SERP の食い違いが大きいほど隙間 |
| 個人ブログの余地 | **25%** | 物理的な空き枠 |
| 権威性 | **20%** | 強豪の存在感 |
| AI検索 引用適性 | **15%** | 将来重要 (現状はまだ AI 検索シェア小さい) |
| 動画/SNS の少なさ | **10%** | 補助指標 |

AI は数値だけでなく、**「なぜこの数値か」を日本語で1文の説明**も返す。

## ④ 実例で見る判定

### 例1: 「ワイヤレスイヤホン 寝るとき おすすめ」 で検索すると

**ステップ②の結果 (上位30件)**

```
🛒 Amazon・楽天・Yahoo:  12件 (40%)
📰 大手メディア (mybest等): 8件 (27%)
📝 個人ブログ:            6件 (20%)
❓ その他:                4件 (13%)
```

**エンジン A の判定**: △ 中 (機会スコア 45)
- 大手 EC が4割もあるので隙間はあるが、mybest 等の比較メディアも一定割合あって楽勝ではない

**エンジン B の AI 判定**: 総合 60

| 観点 | スコア |
|---|---|
| 権威性 | 50 (強豪少なめ) |
| 検索意図のズレ | 70 (比較を求めているのに商品ページが多い) |
| 個人ブログの余地 | 55 (やや空き枠あり) |
| AI検索 引用適性 | 65 (寝るとき×イヤホンは AI も拾いやすい) |
| 動画/SNS の少なさ | 80 (YouTube少ない) |

**AI コメント**:
> mybest が強いが、寝るとき特化の解説が少ない。睡眠×イヤホンに絞った解説記事なら隙間あり。LLMO 観点でも比較的拾われやすい。

**結論**: A= △ / B= 60 → **書く価値ありの中堅 KW**

## ⑤ プラットフォーム占有判定 (どの媒体で書くかの自動振り分け)

SEO で見落とされがちだが超重要な観点。

### 課題

同じ KW で **note には他社の記事が既に上位入りしている** が、**livedoor blog にはまだ無い** という状況がよくある。
note にもう1本書いても、note ドメイン内で同じ KW の競合となり SEO 的に勝ちにくい。一方 livedoor は隙間。

### 仕組み

Brave 上位30件の URL のドメインを見て、各プラットフォーム (note.com / hatenablog.com / livedoor.blog / 等) の出現数をカウント。

```
KW: 「ワイヤレスイヤホン 寝るとき おすすめ」
上位30件のドメイン分布:
  📝 note.com:           3件 ← noteには既に競合あり
  📝 hatenablog.com:     1件 ← はてなにも1件
  📝 livedoor.blog:      0件 ← livedoorは隙間あり！
  📝 ameblo.jp:          0件 ← Amebaも隙間 (※規約でAmazonアフィNG)
```

### UI 表示

各 KW 候補の下に投稿先バッジが並ぶ:

```
投稿先:  ⚠ note 競合3件   ⚠ はてな 競合1件   ✓ livedoor 隙間あり
        (赤 = スキップ推奨)              (緑 = 投稿チャンス)
```

### 「✍ 記事生成」ボタンの自動振り分け

ユーザーが「✍ 記事生成」を押すと、システムが自動的に:

1. **占有なし** (緑バッジ) の投稿先を選んで記事生成
2. 優先順位: note → 他の順 (note が空いていれば note)
3. 全投稿先が占有されている場合 → 警告ダイアログ「すべて競合あり、それでも生成しますか?」

これで「無駄に重複投稿しない」運用が自動化される。

### ビジネス効果

- **SEO 効率 UP**: 競合の少ない媒体に書くので、上位入りしやすい
- **媒体分散**: アクセス源を1媒体に依存させず、複数媒体に分散
- **時間節約**: 「この KW は note でもう書いた他人がいるから、はてなで書こう」という判断を毎回手動でやらなくて済む

## ⑥ 何が「勝てる」「勝てない」を分ける根本要因か

| 要因 | 説明 |
|---|---|
| **検索結果の競合の強さ** | mybest / kakaku.com は、専属ライター数十名 + 月数百万PVの巨大メディア。個人ブログ1人が同じ KW で勝つのはほぼ不可能 |
| **検索ニーズと SERP のマッチ度** | ユーザーが「比較記事を求めている」のに SERP に商品ページしか無い場合、解説記事を書けば一気に上位に入れる可能性 |
| **後発参入の遅さ** | 個人ブログが既に大量参入している KW は、被リンク / 記事数で先発組に勝てない |
| **AI 検索での将来性** | ChatGPT/Perplexity 等が引用しやすい KW (網羅的な解説が必要なもの) は、SEO だけでなく LLMO 流入も狙える |

## ⑦ 現状の限界 (正直な話)

| # | 限界 | 影響 | 将来の対応 |
|---|---|---|---|
| 1 | AI 判断はハルシネーション可能性あり | スコアが実態とずれることがある | エンジン A (ルール) と並べて表示しているので、人間が見比べて最終判断 |

| 5 | ドメインの被リンク数 / 年齢未参照 | 権威性を AI 推定に頼っている | Ahrefs等の有料 API (月$99〜) を契約すれば追加可 |

## ⑨ この機能で実現できる価値

1. **ムダ記事ゼロ運用**: スカウトで ◎ 易 と判定された KW だけ記事化することで、書いた記事の検索上位率が大幅向上
2. **ネタ探しの自動化**: 毎日 Amazon ベストセラーを見て一個一個 SEO を確認する手間が不要
3. **LLMO 時代への先行投資**: AI 検索からの引用適性も同時評価しているので、SEO の次の時代に対応
4. **媒体別の重複投稿を自動回避**: note に既に他社の同KW記事があれば、はてなや livedoor に振り分ける。手動判断不要
5. **判断根拠の可視化**: AI が「なぜこのスコアか」を日本語で説明してくれるので、社員教育や外注先への説明にも使える
